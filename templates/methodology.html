Methodology & disclaimer

Purpose

CryptoStack Tracker is an education-only site built to help its owner learn the crypto tool stack: what trading terminals, scanners, wallets and safety checkers do, and what they charge. It does not pick coins, name tokens to buy, or give trading signals.

How fees are researched

  1. Official sources only. Each fee is read from the vendor's own website, docs or help centre. The exact page is linked on every tool page with the date checked.
  2. No estimates. If a fee could not be read from an official source, the field is left blank. We never fill gaps from reviews, affiliate sites or memory.
  3. Verification labels.
    • Fees verified: every fee figure shown was read from an official page on the date checked.
    • Partly verified: some figures were read from an official page; others (e.g. a consumer plan or a tier with no visible price) could not be, and are blank.
    • Unverified: no fee figure could be read from an official source, so the fee is blank.
  4. Manual updates. Data is re-checked by hand; changes are listed on What's new. There is no automated scraping, and fees can change after the date checked.
  5. Costs not shown. Network priority fees, Jito tips, launchpad/pool fees (for example pump.fun's bonding-curve fee) and slippage are separate from the tool's own fee. See the bonding curve guide.

Referral links

This site is education-only and is not paid to review or rank tools. Outbound links to vendors’ official sites are ordinary documentation links (rel="nofollow noopener") unless a referral URL is stored for that service in data/referrals.json.

When a referral URL is present, the visit button is labelled “Referral link”, uses rel="sponsored nofollow", and carries a one-line disclosure that CryptoStack may earn a commission if you use it. That is not a recommendation to sign up, deposit or trade. Services with an empty referral URL keep their official-site link. New referral URLs can be added by editing only that JSON file and rebuilding. This page does not state a commission rate.

Disclaimer

Not financial advice. Crypto is high risk. Everything here is general education. Nothing is a recommendation to buy, sell or hold any asset, or to use any tool. Most newly launched tokens lose most or all of their value; scams and rugs are common. Safety checkers reduce some risks but cannot guarantee anything. Only use money you can afford to lose entirely, and verify everything on the vendor's own site.

Strategy pages describe risk-management concepts traders talk about, with example numbers used only as illustrations.
