What Elysium is

In official docs, Elysium is “a general-purpose, high-performance L2 for Hyperliquid built by Kinetiq.” It is an Arbitrum Orbit chain (Nitro/ArbOS), operated with Conduit. Transactions run on Elysium; the chain settles to HyperEVM (Hyperliquid’s EVM, chain ID 999).

Kinetiq opened public mainnet on 9 Nov 2026, according to its launch blog and the Elysium docs (which mark both mainnet and testnet as live). The docs, last updated 9 Nov 2026, also state:

  • Blocks are produced at a 100 millisecond canonical cadence, with a perceived transaction receipt of about 300 milliseconds.
  • The execution target is 300 million gas per second, described as validated in load testing before mainnet — a target, not a promise of sustained live throughput.
  • The native gas token is HYPE, the same native coin as HyperEVM. Official docs say HYPE bridges in 1:1 as native gas and withdraws 1:1, with no wrapper and no new gas token.
  • The EVM is stock ArbOS 61, so ordinary EVM tooling is intended to work. Blob transactions are not supported.

Elysium does not introduce its own gas token. KNTQ is Kinetiq’s existing governance token; it is relevant to the sequencer fee split described below, not to paying gas on Elysium.

This Elysium (chain ID 99901) is Kinetiq’s Hyperliquid L2. It is not the older, unrelated “Elysium” networks that appear on some market-data sites.

How it relates to Hyperliquid, HyperEVM and HyperCore

Hyperliquid has more than one layer. The official Elysium docs describe the relationship this way:

  • HyperCore is Hyperliquid’s Layer 1: the spot and perpetual order books, running at about 70 millisecond blocks. Official docs call it the destination for tokens that “graduate” to a HyperCore spot order book, and the venue for possible HIP-3 perpetual listings.
  • HyperEVM is Hyperliquid’s EVM (chain ID 999). Official docs say HyperEVM is deliberately constrained (3 million gas per second on small blocks; 30 million gas only on 60-second “big blocks”) so that EVM activity can stay in step with HyperCore. Elysium settles to HyperEVM, and HyperEVM is the hop between Elysium and HyperCore for tokens.
  • Elysium is the new L2: a higher-throughput EVM environment that stays inside the Hyperliquid ecosystem. Assets, settlement and market structure are described as Hyperliquid-native.

Official docs also describe an intended token path: a token can launch on an Elysium AMM, be mirrored to HyperEVM, graduate to a HyperCore spot order book, and possibly reach a perpetual listing through HIP-3. That is a design described by Kinetiq, not a forecast that any particular token will complete it or be worth anything. Most new-chain token launches fail.

Direct HyperCore read and write from Elysium contracts is not part of day-one mainnet. Official docs say those arrive in an ArbOS upgrade about four weeks after mainnet. See What is planned next.

How bridging is described

This is a description of the official path, not an instruction to move funds. If you do not need to use Elysium, you do not need to bridge.

Official docs and the 9 Nov 2026 launch blog point to the official bridge and network details at elysium.kinetiq.xyz/bridge, with the longer explanation in Token bridging on Elysium.

  1. Verify the network only from official docs. Confirm chain ID 99901, the official public RPC and the official explorer on Connecting to Elysium. Fake “Elysium” sites and RPCs are a common phishing pattern on new chains. Bookmark the elysium.kinetiq.xyz and kinetiq.xyz hosts from those docs; do not follow a link from a DM, a comment reply or a look-alike domain. Never paste a seed phrase or private key into a bridge or “support” page.
  2. HYPE on HyperEVM is the gas path. Official docs say you deposit HYPE on HyperEVM and receive native HYPE gas on Elysium 1:1, or burn native HYPE on Elysium to withdraw HYPE 1:1. There is no wrapper in this path. Bridge fees on the EVM legs are described as paid in native HYPE.
  3. Use only the official bridge URL above (or the flow documented on the official docs site). Other front-ends may exist later; this page does not recommend them.
  4. Expect a long wait on the way back. Elysium is an optimistic rollup. Official docs say canonical withdrawals finalize after a challenge period of about 5.5 days on mainnet. Burning a representation of a HyperEVM token on Elysium likewise releases the escrow on HyperEVM after that challenge period. Plan on that delay; a “fast bridge” that is not the canonical official path is a different trust model and is not described here.
  5. Other official routes exist for tokens, not only native HYPE. The canonical bridge locks an ERC-20 on HyperEVM and mints a 1:1 representation on Elysium. The mirror bridge does the reverse for Elysium-native tokens (after a one-time setup). A further “Core linkage” path is how a token on HyperEVM can be connected to HyperCore. Official docs say fee-on-transfer and rebasing tokens are not currently supported.

The sequencer fee model

Users pay transaction fees in HYPE. Official fees docs say that on mainnet, priority fees are collected by the network, not burned, and that there is no parent-chain data fee in the usual per-byte sense because data availability is committee-style (see risks below).

Separately, Kinetiq has stated how it intends to allocate sequencer revenue. The 27 Aug 2026 announcement, the Kinetiq homepage, the 9 Nov 2026 launch blog and the KNTQ docs agree on the split:

  • 50% to programmatic purchases of KNTQ on the open market. Official KNTQ docs say purchased tokens, along with fees already paid in KNTQ, are sent to the Hyperliquid Assistance Fund, which those docs describe as permanently removing them from supply.
  • 25% to builders whose applications drive blockspace demand, which Kinetiq says can be used for incentives, rebates, liquidity programs or application-level mechanisms.
  • 25% to the Kinetiq treasury for operations.

That is a stated policy, not a guarantee of buyback size, of KNTQ demand, or of builder payouts. This page does not treat the split as a reason to buy or sell anything.

As factual schedule context, official KNTQ docs (last updated 16 Sep 2026) say the KNTQ genesis was 27 Nov 2025, with a maximum supply of 1 billion, and that core contributors and investors share a three-year vest: a one-year cliff and then two years of monthly linear vesting. The cliff date implied by that official schedule is 27 Nov 2026. An unlock is a supply event, not a trading signal.

What is planned next

Official “What is Elysium” and related docs split the roadmap into three stages:

  1. Launch (now, as of the 9 Nov 2026 mainnet). Stock ArbOS, native HYPE gas, 100 ms blocks, AnyTrust data availability, HyperEVM settlement, and the token-bridging surface (canonical bridge, mirror bridge, and the HyperCore graduation path).
  2. About four weeks after mainnet. An ArbOS network upgrade is planned to add the HyperCore read and write edge: a native HyperCore market-data precompile (live order books, prices, balances and positions, readable by contracts for ordinary call gas) and the ElysiumCoreWriter predeploy (contracts can emit order intents; a trade-only agent on the user’s own HyperCore account submits them). Official trading docs say custody is meant to stay in the user’s HyperCore account, and that the agent can be revoked on HyperCore without involving Elysium. These features are documented as not shipping on day-one stock ArbOS. Kinetiq has not, in the docs checked on 10 Nov 2026, published a calendar date such as 7 Dec 2026; “about four weeks after mainnet” is the official wording.
  3. Hardening (later). Official docs mention MEV telemetry and native Timeboost, further block-time tuning, a multi-member data-availability committee, permissionless proving (Arbitrum BoLD), and audits. These are plans, not completed work.

An earlier Kinetiq blog (27 Aug 2026) described a customized “L1Read” precompile. Current official docs use the names above. This page follows the docs.

Ecosystem (listed, not endorsed)

Kinetiq’s 9 Nov 2026 launch blog names infrastructure and application partners including Alchemy, Arbitrum, Conduit and Uniswap. That blog says Uniswap is part of the infrastructure from day one, and that hooks let teams customise how pools behave.

The official ecosystem directory at elysium.kinetiq.xyz/ecosystem also lists many other projects. Among them, as of the 10 Nov 2026 sitemap, are DEX and routing names such as 0x and KyberSwap, launch-related names such as Pump.fun and fomo, bridging names such as Wormhole and Mayan, and the wallet name Zerion, plus a long tail of launchpads, NFT and game pages. A listing in that directory means Kinetiq has published a page for the name. It does not mean the app is live, audited, or safe, and it is not a recommendation to use it.

New chains often publish large directories on day one. Most new-chain projects fail, go unmaintained, or turn out to be marketing pages. Treat every app as unproven unless you have checked it yourself against official contract addresses and independent sources.

Risks

  • It is a new mainnet. Public mainnet opened on 9 Nov 2026. Software, bridges, sequencers and apps can fail, pause or get exploited. Official docs still list later audits and permissionless proving as future work.
  • Optimistic withdrawals are slow. A canonical withdrawal has a challenge period of about 5.5 days. If you cannot wait, you may be stuck, or tempted by unofficial “fast” routes that add extra trust assumptions.
  • The launch security posture is centralised in several ways. Official security docs say Elysium starts with a single sequencer, permissioned validation (with a later path to Arbitrum BoLD), and a single Conduit-operated data-availability server. Until a multi-member committee is live, official docs say “AnyTrust” describes the mechanism, not k-of-n committee security. If that server is unavailable, the docs say the chain falls back to posting full data to HyperEVM, which raises costs. Users are said to keep forced inclusion via the delayed inbox on HyperEVM, and withdrawal safety via the challenge period — those are design claims to read in the official docs, not guarantees against every failure mode.
  • Phishing and fake networks. Confirm chain ID 99901 and URLs only from official docs. Impersonator RPCs, “support” accounts and look-alike bridges are common around launches.
  • Apps and token launches are high risk. An intended path from an Elysium AMM to HyperCore is not a quality filter. Most new tokens go to zero. Do not treat a listing, a “graduation” story or a directory badge as due diligence.
  • Fee-split and unlock facts are not investment merits. Stated buybacks, burns and a 27 Nov 2026 cliff are descriptions of policy and schedule. They do not imply a price, a yield or a reason to buy KNTQ.

FAQ

What is Elysium?

Kinetiq’s general-purpose Layer 2 for the Hyperliquid ecosystem: an Arbitrum Orbit chain that settles to HyperEVM and uses HYPE as gas. Public mainnet opened on 9 Nov 2026.

What is Elysium’s chain ID?

Mainnet chain ID is 99901, according to official docs and a live query of the public RPC on 10 Nov 2026. Testnet is 99801. Re-check the official connecting page if you are configuring a wallet; do not copy a chain ID from an unofficial message.

What RPC should be used?

The official public RPC is https://rpc.elysium.kinetiq.xyz. Official docs also list provider endpoints and warn that the public RPC is shared. Only add an RPC you have verified against those docs.

How do you bridge to Elysium?

Official materials point to elysium.kinetiq.xyz/bridge. HYPE is described as moving 1:1 from HyperEVM as native gas. This page does not ask you to bridge. If you ever use the official path, verify the URL and network settings first, and read the withdrawal warning below.

How long do withdrawals take?

Official docs say canonical optimistic withdrawals have a challenge period of about 5.5 days on mainnet.

Does Elysium have its own token?

Elysium’s gas token is HYPE, not a new Elysium coin. KNTQ is Kinetiq’s existing governance token and is named in the sequencer fee split. That is not a recommendation of either asset.

When can contracts read and trade HyperCore from Elysium?

Official docs say the market-data precompile and ElysiumCoreWriter predeploy ship in an ArbOS upgrade about four weeks after mainnet. They are not described as live on day-one stock ArbOS. No calendar date was published in the official docs checked on 10 Nov 2026.

Is this the same as other projects named Elysium?

No. This page is only about Kinetiq’s Hyperliquid L2 (chain ID 99901). Other chains or tokens that reuse the name are unrelated unless official Kinetiq docs say otherwise.
