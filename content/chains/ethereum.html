What Ethereum is

Ethereum is a layer-1 smart-contract network. Official docs describe proof of stake: validators stake ETH, and in each slot a validator is selected to propose a block. The canonical mainnet chain ID is 1. Many Layer 2 networks settle to Ethereum; those are separate chains and have their own gas, explorers and withdrawal rules (see Base in this series).

You can read the chain through an explorer without running a node or connecting a wallet. That is all this page assumes.

Gas token, fees and speed

The native coin is ETH. Transaction fees are priced in gwei (1 gwei = 0.000000001 ETH). Official gas docs describe the post-EIP-1559 model:

  • A transaction pays for gas used multiplied by a gas price made of a base fee plus an optional priority tip.
  • The base fee is burned. The tip, if any, is paid to the validator that includes the transaction.
  • The base fee moves up or down with demand. There is no single official “typical USD fee,” and quoting one would go stale quickly. Check a current gas tracker on the day you care about, and treat USD conversions as snapshots, not promises.

Official block docs say Ethereum time is divided into 12-second slots. When the selected proposer is online, a block is produced in that slot, so the block time is typically 12 seconds. Slots can be empty if a proposer is offline. Economic finality comes later, after subsequent checkpoints; a single included block is not the same thing as finalized history.

Official docs also describe a target block size of 30 million gas and a limit of 60 million gas (twice the target). Those protocol limits are not a fee quote.

Official explorer

ethereum.org’s block-explorer documentation lists several public explorers. The most commonly used independent explorer is etherscan.io. Use it to read a transaction, an address or a token contract without connecting a wallet. Bookmark official URLs yourself. Do not trust an explorer or “support” link from a DM, a comment reply or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

These are commonly used public venues, not recommendations, and not a complete list.

  • Uniswap is the principal decentralized exchange associated with Ethereum. Many ERC-20 tokens, including memecoins, trade on Uniswap pools.

Unlike some other chains in this series, Ethereum does not have a single official or universally dominant memecoin launchpad that this page can name from official chain documentation. Tokens are often created as ERC-20 contracts and listed on an AMM. A Uniswap pool, a verified-contract badge or a social announcement is not evidence that a token is safe or worth anything. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of how assets typically move, not an instruction to move funds. If you do not need an asset on Ethereum, you do not need a bridge.

Ethereum is the settlement layer for many official Layer 2 bridges. Moving ETH or tokens from an L2 back to Ethereum usually follows that L2’s canonical withdrawal path and delay (for Base, official docs currently describe a 5-day single-proof window, or 1 day when both TEE and ZK proofs support the same proposal; see What is Base?). Moving assets between Ethereum and other layer-1 networks usually means a third-party bridge, each with its own trust model.

If you ever use a bridge, start from the destination chain’s official documentation, double-check the domain and chain ID (Ethereum mainnet is 1), and treat unsolicited “bridge” links and fake RPCs as phishing. A wrong-network transfer can permanently lose funds. This page does not name, rank or endorse any third-party bridge.

How to evaluate a token on Ethereum

This is a reading list, not a trading method and not a reason to buy anything.

  • Read the contract, holders and transactions on Etherscan.
  • Look at the pool and recent trades on a public screener such as DEX Screener.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use contract-screening tools such as GoPlus and Token Sniffer as one input only; a “passed” badge is not a safety guarantee.
  • Read spotting rugs and crypto research tools for broader context.

None of those tools can make a token safe. They can only show you what is already on-chain.

Risks

  • New tokens are usually worthless. Anyone can deploy an ERC-20 and create a pool. Hidden mint functions, seller wallets and honeypots are common.
  • Variable fees. During congestion, base fees and tips can rise sharply. A USD figure from last week is not a quote for today.
  • Phishing and fake tokens. Look-alike tickers, fake explorers, airdrop sites and malicious approvals are routine scams.
  • Bridging and wrong-network risk. Sending assets to the wrong chain ID, or through a fake front-end, can lose them with no recourse.
  • Smart-contract risk. DEX and token contracts can have bugs or admin controls that are not obvious from a ticker.

Nothing on this page is financial advice, a recommendation to hold ETH, or a suggestion to launch or trade a token.
