Official developer docs describe an EVM-equivalent chain on an enhanced OP Stack, OKB as the gas token, a mainnet chain ID of 196, and 1-second block times. This page is a plain-language snapshot of those official figures. It is not a reason to use X Layer or to buy any token.

What X Layer is

Official X Layer developer docs describe the network as an Ethereum Layer 2 built by OKX, with a fully EVM-equivalent execution environment. The docs say X Layer has evolved to adopt the Optimism Stack (OP Stack). Earlier public materials referred to Polygon CDK; current official developer documentation is the OP Stack description, and that is what this page follows.

The official mainnet chain ID is 196. Official docs also describe a trusted sequencer (op-node with op-reth) and a claimed capacity of up to 20,000 transactions per second. Treat that TPS figure as a stated capacity, not a measurement of live demand. A 7-day challenge period for fraud proofs is stated in the same official architecture overview. Later sections of those docs also describe an AggLayer pessimistic-proof (PP) path, with ZK proofs, for cross-chain settlement. Withdrawal mechanics can involve more than one official description; check the current official bridge docs for the path that applies to a given withdrawal.

Gas token, fees and speed

The gas token is OKB. Official docs say OKB is the native gas token, with a fixed supply of 21 million after burns and upgrades, and that an Ethereum L1 version of OKB has been phased out. Those are supply facts from official documentation, not a reason to buy or hold OKB.

Official architecture docs state 1-second block times. Official docs also mention “negligible gas fees”; this page does not copy a USD figure, because dollar costs move with the price of OKB and with the gas price of the day. Check a current explorer gas reading rather than a marketing phrase.

Official network-information docs list public RPCs at https://rpc.xlayer.tech and https://xlayerrpc.okx.com, and they note rate limits (official RPC docs have cited 100 requests per second per IP).

Official explorer

Official network docs list okx.com/web3/explorer/xlayer as the mainnet explorer. You can look up a transaction, an address or a token without connecting a wallet. Bookmark official URLs yourself. Do not trust an explorer or RPC from a DM or a look-alike domain, and never paste a seed phrase or private key into a website. This page does not ask you to create an OKX account.

DEXs and memecoin launchpads

Official developer documentation does not name a single canonical memecoin launchpad that this page can treat as official, and this page does not invent DEX names. A pool on X Layer is not evidence that a token is safe or worth anything. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of official documentation, not an instruction to move funds. If you do not need an asset on X Layer, you do not need to bridge.

Official X Layer bridge documentation points the community to third-party and official portal options at web3.okx.com/xlayer/bridge, and it describes deposit and withdrawal flows between Ethereum and X Layer. Official architecture docs also mention a 7-day fraud-proof challenge period and a separate AggLayer proof path for some withdrawals. Third-party “fast bridges” are a different trust model. This page does not rank them.

If you ever use a bridge, start from official X Layer docs, confirm chain ID 196 on X Layer and chain ID 1 on Ethereum, double-check the domain, and treat unsolicited bridge links as phishing. A wrong-network transfer can permanently lose funds.

How to evaluate a token on X Layer

This is a reading list, not a trading method and not a reason to buy anything.

  • Read the contract, holders and transactions on the official X Layer explorer.
  • Look at the pool and recent trades on a public screener such as DEX Screener, if the pair is listed there.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use GoPlus and Token Sniffer only if they actually support X Layer for that contract.
  • Read spotting rugs and crypto research tools.

None of those tools can make a token safe.

Risks

  • Layer-2 and sequencer trust assumptions. Official docs describe a trusted sequencer. Inclusion can be fast; canonical security still depends on Ethereum settlement and the published proof system.
  • Two official withdrawal descriptions. A 7-day challenge period and an AggLayer pessimistic-proof path both appear in official docs. Confirm the path that applies before assuming a delay.
  • New tokens are usually worthless.
  • Phishing and look-alike “OKX” or “X Layer” sites. Start from official developer docs, not from a chat link. This page does not ask you to sign up for an exchange.
  • Wrong-network transfers. X Layer addresses look like Ethereum addresses. Confirm chain ID 196 versus 1 (and versus other EVM chains) before sending anything.

Nothing on this page is financial advice, a recommendation to hold OKB, or a suggestion to launch or trade a token.
