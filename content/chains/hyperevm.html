HyperEVM is the EVM environment of the Hyperliquid blockchain, not a separate layer-1 of its own. Official docs say it is secured by the same HyperBFT consensus as HyperCore, uses HYPE as gas, and has mainnet chain ID 999. Official materials also describe the HyperEVM as still in an alpha / gradual-rollout stage, with a dual-block design: 1-second small blocks (3 million gas) and 1-minute big blocks (30 million gas). This page is a plain-language snapshot of those official figures. It is not a reason to use HyperEVM or to buy any token.

Last verified 10 Nov 2026 (Asia/Calcutta) against official Hyperliquid documentation. Network details can change; check the official docs before you rely on a figure.

What HyperEVM is

Official Hyperliquid docs describe two parts of one blockchain: HyperCore (the native spot and perpetual order books) and HyperEVM (an EVM execution environment). HyperEVM is not a separate chain in the usual L1/L2 sense. It is built as part of Hyperliquid’s execution and inherits security from HyperBFT, the same consensus as HyperCore. The official mainnet chain ID is 999 (testnet is 998). The official JSON-RPC endpoint listed in docs is https://rpc.hyperliquid.xyz/evm.

Official docs say the HyperEVM uses the Cancun EVM hard fork without blobs, with EIP-1559 enabled. They also state that, unlike most EVM chains, priority fees are burned as well as the base fee, because HyperEVM uses HyperBFT rather than a separate proposer tip. Official docs still describe the HyperEVM as being in an alpha stage, with throughput increased gradually so that HyperCore is not starved of blockspace.

Kinetiq’s Elysium is a separate Layer 2 that official Elysium docs say settles to HyperEVM. That relationship is explained on the Elysium guide; this page is about HyperEVM itself.

Gas token, fees and speed

The native gas token is HYPE, with 18 decimals on both mainnet and testnet according to official docs. This page does not quote a USD transaction cost.

Official dual-block architecture docs (checked 10 Nov 2026) describe an initial, conservative configuration:

  • Small / fast blocks: 1 second, with a 3 million gas limit.
  • Big / slow blocks: 1 minute, with a 30 million gas limit.

Official docs say that configuration is expected to change as throughput is increased in later upgrades, so treat the numbers as the documented starting design, not a permanent guarantee.

Official explorers

Official “how to use the HyperEVM” docs list two public explorers: hyperevmscan.io and hyperscan.com. You can look up a transaction, an address or a token without connecting a wallet. Bookmark official URLs from the docs. Do not trust an explorer or RPC from a DM, a comment reply or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

Official Hyperliquid docs list third-party tooling and explorers. They do not name a single official memecoin launchpad that this page can treat as canonical, and this page does not inventory or endorse DEX venues. A pool on HyperEVM is not evidence that a token is safe or worth anything. Most new tokens fail, and a newer, still-alpha execution environment adds tooling risk. See spotting rugs.

Bridging basics

This is a description of official documentation, not an instruction to move funds. If you do not need an asset on HyperEVM, you do not need to bridge or transfer.

Official docs describe two different moves that people often lump together:

  • HyperCore ↔ HyperEVM is an in-protocol transfer of balances (including HYPE for gas) between Hyperliquid’s two environments, using the official transfer controls documented in Hyperliquid’s “How to use the HyperEVM” pages. Official docs warn that each spot asset has its own transfer path, and that sending the wrong asset to the wrong path can lose it. This page does not publish contract or transfer addresses.
  • Other networks ↔ HyperEVM usually means a third-party bridge, each with its own trust assumptions, fees and delays. Official docs mention bridges as a way to obtain gas; this page does not name, rank or endorse them.

If you ever move funds, start from official Hyperliquid documentation, confirm chain ID 999, and treat unsolicited “bridge” links and fake RPCs as phishing. A wrong-network transfer can permanently lose funds.

How to evaluate a token on HyperEVM

This is a reading list, not a trading method and not a reason to buy anything. Some Ethereum-oriented scanners have incomplete coverage of HyperEVM.

  • Read the contract, holders and transactions on HyperEVMScan or Hyperscan.
  • Look at the pool and recent trades on a public screener such as DEX Screener, if the pair is listed there.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use contract-screening tools such as GoPlus and Token Sniffer only if they actually support HyperEVM for that contract.
  • Read spotting rugs, crypto research tools, and the Elysium explainer if you are looking at the related L2.

None of those tools can make a token safe. They can only show you what is already on-chain.

Risks

  • Alpha / gradual rollout. Official docs say higher throughput and some system contracts have been rolled out carefully, and that the environment is still described as alpha. Tooling, RPC behaviour and block limits can change.
  • Shared blockspace with HyperCore. Official docs say the HyperEVM was launched with constrained throughput so that it would not degrade HyperCore. Gas can spike when demand exceeds that supply.
  • Two environments, one blockchain. Confusing HyperCore (spot/perps) with HyperEVM (EVM balances) is a common way to send assets to a place a venue does not support.
  • New tokens are usually worthless.
  • Phishing and fake official sites. Prefer URLs published in official Hyperliquid docs.

Nothing on this page is financial advice, a recommendation to hold HYPE, or a suggestion to launch or trade a token.
