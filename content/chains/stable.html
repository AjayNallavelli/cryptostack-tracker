Stable is a public, EVM-compatible payments layer-1. Official docs say mainnet is live, USDT0 is the native gas token (and also an ERC-20), the chain ID is 988, blocks are about 0.7 seconds, and the chain provides single-slot finality. Official materials also describe a STABLE governance token used in delegated proof of stake; that is a protocol fact, not a reason to buy it. This page is a plain-language snapshot of those official figures. It is not a reason to use Stable or to buy any token.

What Stable is

Official docs describe Stable as a payments layer 1 where USDT0 is the native gas token, with sub-second settlement and EVM compatibility. Official mainnet-information docs list the network name as Stable Mainnet, chain ID 988, and a public RPC at https://rpc.stable.xyz (official docs also note a rate limit of 1,000 requests per 10 seconds per IP on that public endpoint).

Official tokenomics docs say STABLE is the mainnet governance token, used in delegated proof of stake to secure the network and to govern upgrades, and that stakers may receive a share of USDT0 gas revenue distributed by validators. That is a stated official model, not a forecast of yield and not a recommendation to buy or stake STABLE.

Official finality docs say Stable provides single-slot finality: once a transaction is included in a valid block, official docs treat the state change as final and irreversible. Some language on the same official finality page still refers to a “public testnet phase” for compatibility commitments; the official mainnet-information page, however, documents a live mainnet. This page treats mainnet as live per the mainnet-information docs, and treats leftover testnet wording on other pages as a reason to re-check official docs rather than as proof that mainnet is not shipping.

Gas token, fees and speed

The gas token is USDT0. Official docs say USDT0 is both the chain’s native asset and an ERC-20, with 18 decimals in the native gas / chain-information table (this can differ from the 6-decimal USDT people are used to on other chains — confirm official docs before assuming a decimal count). Official how-to docs also say a standard EIP-1559 transaction on Stable should set maxPriorityFeePerGas to 0, because the fee market is described as base-fee only. Official homepage and overview copy mention “sub-cent” fees; treat that as qualitative marketing language, not a guaranteed USD quote, and check a live fee estimate on the date you care about.

Official mainnet-information docs list a block time of about 0.7 seconds. Official overview copy also describes sub-second finality, consistent with the single-slot-finality explanation.

Official explorer

Official mainnet-information docs list stablescan.xyz as the explorer. You can look up a transaction, an address or a token without connecting a wallet. Bookmark official URLs from docs.stable.xyz. Do not trust an explorer or RPC from a DM or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

Official DEX documentation says Stable is on the official Uniswap v3 deployments list, and that routing is available through the project’s frontend at swap.stable.xyz. A Uniswap deployment or an official frontend is not an endorsement by this site, and it is not evidence that any particular token is safe. Official docs do not name a single canonical memecoin launchpad, and this page does not invent one. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of official documentation, not an instruction to move funds. If you do not need an asset on Stable, you do not need to bridge.

Official docs describe bridging USDT0 to Stable and list official bridge references and third-party interfaces. Each route has its own trust assumptions, fees and delays. This page does not name, rank or endorse a third-party bridge, does not publish contract addresses, and does not tell you to buy USDT or USDT0.

If you ever use a bridge, start from official Stable docs, confirm chain ID 988, double-check the domain, and treat unsolicited bridge links as phishing. Decimal differences between USDT0 on Stable and USDT on other chains are a practical way to get an amount wrong.

How to evaluate a token on Stable

This is a reading list, not a trading method and not a reason to buy anything. Coverage on a newer chain can be uneven.

  • Read the contract, holders and transactions on Stablescan.
  • Look at the pool and recent trades on a public screener such as DEX Screener, if the pair is listed there.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use GoPlus and Token Sniffer only if they actually support Stable for that contract.
  • Read spotting rugs and crypto research tools.

None of those tools can make a token safe.

Risks

  • Newer payments L1. Official mainnet exists, but tooling, bridges and third-party coverage can still be thinner than on long-running chains. Some official pages still mix mainnet and leftover testnet wording.
  • USDT0 decimals and dual representation. Official docs treat USDT0 as both native gas and an ERC-20. A tool or wallet written for 6-decimal USDT can display or send the wrong amount.
  • Governance token vs gas token. STABLE and USDT0 are different official assets. Confusing them is a way to send value to the wrong place.
  • New tokens are usually worthless.
  • Phishing. Prefer docs.stable.xyz and stablescan.xyz, not a chat link. The name “Stable” is easy to spoof.

Nothing on this page is financial advice, a recommendation to hold USDT0 or STABLE, or a suggestion to launch or trade a token.
