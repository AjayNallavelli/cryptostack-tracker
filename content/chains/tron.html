TRON is a public layer-1 blockchain. It does not use Ethereum-style gas. Official developer docs describe a Delegated Proof of Stake network with 27 Super Representatives, a block time of about 3 seconds, and a fee model based on Bandwidth and Energy, with TRX burned when those resources are insufficient. This page is a plain-language snapshot of those official figures, the official explorer, and commonly used TRON venues for new tokens. It is not a reason to use TRON or to buy any token.

What TRON is

Official developer docs describe TRON as a layer-1 smart-contract network using Delegated Proof of Stake (DPoS). 27 Super Representatives produce blocks. That is a different validator model from Ethereum’s large proof-of-stake set or Solana’s validator cluster, with a correspondingly different set of operational and governance assumptions. Official introductory material is published at developers.tron.network.

TRON’s account and contract model is not identical to Ethereum’s, even when a wallet UI makes them look similar. Confirm you are on TRON mainnet, and on the official explorer, before signing anything.

Resources, fees and speed

TRON does not use Ethereum-style gas paid as “gwei of ETH.” Official docs describe two resources:

  • Bandwidth, used for ordinary transfers and the bytes in a transaction.
  • Energy, used for smart-contract execution.

Accounts can obtain Bandwidth and Energy by staking or freezing TRX, according to official resource-model docs. When an account does not have enough of either resource, TRX is burned to pay for the shortfall. Per-unit burn prices are published in official documentation and can change; this page does not copy a sun-per-unit figure that may go stale. Check the official resource-model docs on the date you care about rather than treating a cached number as current. There is also no single official “typical USD fee” that would stay accurate.

Official docs describe a block time of about 3 seconds. They also describe solidification (a stronger confirmation than “included in one block”) when at least 19 distinct active Super Representatives have produced at that height, which official material says typically takes about one minute. Inclusion in a block is not the same thing as a solidified block.

Official explorer

The official explorer is tronscan.org. You can look up a transaction, an account or a TRC-20 token without connecting a wallet. Bookmark that official URL yourself. Do not trust an explorer or “support” link from a DM, a comment reply or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

These are commonly used public venues described in official SUN.io materials. They are not recommendations, and this is not a complete list.

  • SUN.io publishes SunSwap, a decentralized exchange on TRON, and SunPump, a memecoin launchpad. Official product materials describe SunPump as using a bonding-curve launch, with liquidity later placed on SunSwap (SunSwap V2 is the venue named in those materials).

A completed bonding curve or a SunSwap pool does not mean a token is safe, liquid or worth anything. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of how assets typically move, not an instruction to move funds. If you do not need an asset on TRON, you do not need a bridge.

TRON is a layer 1, so there is no single official “canonical withdrawal” window of the kind Ethereum Layer 2s use. Moving assets between TRON and other networks usually means a third-party bridge or a messaging protocol, each with its own trust assumptions, fees and delays. Start from official project documentation, not from a link in a chat. This page does not name, rank or endorse any bridge.

If you ever use a bridge, double-check the domain, confirm you selected TRON (and the intended counterpart network), and treat unsolicited “bridge” links and fake explorers as phishing. TRON addresses do not use the same 0x format as Ethereum; sending assets to the wrong address format or the wrong network can permanently lose them.

How to evaluate a token on TRON

This is a reading list, not a trading method and not a reason to buy anything. Some Ethereum-oriented scanners have weaker or no coverage of TRC-20 tokens.

  • Read the contract, holders and transactions on TRONSCAN.
  • Look at the pool and recent trades on a public screener such as DEX Screener, if the pair is listed there.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Do not assume an Ethereum contract scanner will produce a meaningful result for a TRON token. If a tool’s own docs do not say it supports TRON, treat a missing or generic result as “not checked,” not as a pass.
  • Read spotting rugs and crypto research tools for broader context.

None of those tools can make a token safe. They can only show you what is already on-chain.

Risks

  • Different fee and account model. People who are used to Ethereum gas can misread Bandwidth, Energy and TRX burns, or sign a transaction they did not intend.
  • New tokens are usually worthless. Bonding-curve launches on SunPump, like launchpads on other chains, do not remove insider wallets or malicious contracts.
  • Phishing. Fake explorers, airdrop sites and unofficial wallet pop-ups try to steal keys. Prefer tronscan.org and official developer docs.
  • Bridging and address-format risk. TRON addresses are easy to confuse with “just another network” in a multi-chain wallet UI. A wrong destination can lose funds.
  • Consensus model. A 27-producer DPoS set is a different security and governance model from a large proof-of-stake validator set. Read official docs rather than marketing comparisons.
