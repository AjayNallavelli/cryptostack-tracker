Avalanche is a public layer-1 network whose Primary Network runs three chains. Most smart-contract and token activity that this page describes happens on the Contract Chain (C-Chain), an EVM environment with chain ID 43114 and AVAX as gas. Official docs say the Helicon upgrade activated on mainnet on 22 September 2026, introducing Continuous Execution and a validator-voted minimum base fee. This page is a plain-language snapshot of those official figures. It is not a reason to use Avalanche or to buy any token.

What Avalanche is

Official Avalanche docs describe a heterogeneous network: many blockchains, including application-specific Avalanche L1s, rather than one shared chain for every app. The Primary Network is a special Avalanche L1 that runs three built-in chains:

  • The Contract Chain (C-Chain) — an EVM, chain ID 43114, where Solidity contracts and most DEX activity live. Official public RPC: https://api.avax.network/ext/bc/C/rpc.
  • The Platform Chain (P-Chain) — validator, staking and Avalanche L1 management.
  • The Exchange Chain (X-Chain) — transfers of Avalanche Native Tokens, including some AVAX transfers.

Official docs also say a node can become a Primary Network validator by staking at least 2,000 AVAX. That is a protocol threshold, not a suggestion to stake or to buy AVAX. Other Avalanche L1s are separate networks with their own rules and are not covered here.

The Helicon upgrade activated on mainnet on 22 September 2026 at 15:00 UTC. Official docs say the C-Chain now runs the Continuous Execution VM (ACP-194), which decouples consensus from execution, and that the C-Chain minimum gas price is voted by validators (ACP-283).

Gas token, fees and speed

The gas token on the C-Chain is AVAX. Official fee docs describe an EIP-1559-style market (a base fee plus an optional priority tip). Unlike Ethereum, official Avalanche fee docs say both the base fee and the priority fee are burned.

Since Helicon, official docs say the minimum base fee is a dynamic parameter set by stake-weighted validator preference, with no upper bound. Official transaction-fee docs note that in late September 2026, mainnet validators raised the minimum from 1 wei to 5 nAVAX, and that on 3 October 2026 the mainnet base fee was at or near that minimum. That is a dated official snapshot, not a current quote. Read the live base fee from an official RPC or a current official gas tracker before relying on a number.

Block time is also no longer a single fixed official interval. Official ACP-226 materials describe a dynamic minimum block delay, with a protocol floor of 1 millisecond, configured at activation to stay close to the C-Chain’s prior target of about 2 seconds. The realized interval can change. This page does not treat “2 seconds” as a guaranteed current block time.

Official explorer

Official Primary Network docs list explorer.avax.network/c-chain as the C-Chain explorer, with corresponding official explorers for the P-Chain and X-Chain on the same host. You can look up a transaction, an address or a token without connecting a wallet. Bookmark official URLs yourself. Do not trust an explorer or RPC from a DM or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

Tokens on Avalanche typically trade on C-Chain AMMs. Official Primary Network documentation does not name a single canonical DEX or memecoin launchpad that this page can treat as official, and this page does not invent names. A C-Chain pool is not evidence that a token is safe or worth anything. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of official documentation, not an instruction to move funds. If you do not need an asset on Avalanche, you do not need to bridge.

Moving AVAX inside Avalanche (between the X-, P- and C-Chains) is an official intra-network transfer, with its own fee and confirmation rules, and is not the same as a bridge to Ethereum or another L1. Moving assets between Avalanche and other networks usually means an official or third-party bridge, each with its own trust assumptions, fees and delays. Start from official Avalanche documentation rather than a link in a chat. This page does not name, rank or endorse third-party bridges.

If you ever use a bridge, confirm you selected the Avalanche C-Chain, chain ID 43114 (and the intended counterpart network), double-check the domain, and treat unsolicited “bridge” links and fake RPCs as phishing. Sending assets to the X-Chain or P-Chain when a venue expects the C-Chain is a common mistake.

How to evaluate a token on Avalanche

This is a reading list, not a trading method and not a reason to buy anything.

  • Read the contract, holders and transactions on the official C-Chain explorer.
  • Look at the pool and recent trades on a public screener such as DEX Screener.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use GoPlus and Token Sniffer as one input only; a “passed” badge is not a safety guarantee.
  • Read spotting rugs and crypto research tools.

None of those tools can make a token safe.

Risks

  • Three built-in chains. The C-Chain is not the P-Chain or the X-Chain. A wrong internal destination can park funds where a wallet or venue will not show them.
  • Post-Helicon fee and timing changes. Official docs warn that Continuous Execution changes when state is available relative to acceptance, and that the minimum base fee can be moved by validator vote. Older “typical fee” or “2-second block” figures can be stale.
  • New tokens are usually worthless.
  • Phishing and fake RPCs. Prefer docs.avax.network and the official explorer host.
  • Other Avalanche L1s are not the C-Chain. A custom Avalanche L1 can have a different gas token, chain ID and security model.

Nothing on this page is financial advice, a recommendation to hold AVAX, or a suggestion to launch or trade a token.
