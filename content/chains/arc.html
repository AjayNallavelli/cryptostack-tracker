Arc is a public, EVM-compatible layer-1 blockchain built by Circle, designed around stablecoins. Official docs say mainnet is live, USDC is the native gas token, the chain ID is 5042, blocks are about 0.5 seconds, and finality is deterministic and sub-second. Official docs also describe a permissioned validator set (with permissionless developer access) and several EVM differences from Ethereum, including native USDC using 18 decimals rather than 6. This page is a plain-language snapshot of those official figures. It is not a reason to use Arc or to buy any token.

Last verified 10 Nov 2026 (Asia/Calcutta) against official Arc documentation. Network details can change; check the official docs before you rely on a figure.

What Arc is

Official Arc docs describe a purpose-built layer 1 for stablecoin-native financial applications: payments, lending, FX, treasury and similar uses. There is no separate volatile native gas coin. Official docs say USDC is the gas token, with EURC and USYC also natively supported. That is a design description, not a recommendation to hold those assets.

Official architecture docs split the network into a consensus layer built on Malachite BFT and an execution layer running Reth (an EVM at the Osaka hard-fork baseline). Official network tables say validator participation is permissioned and developer access is permissionless. A permissioned validator set is a different security and governance model from a large open proof-of-stake set. Official docs also say mainnet and testnet are both available; this page is about mainnet (chain ID 5042). Testnet is chain ID 5042002.

Official “EVM differences” docs warn that several behaviours diverge from Ethereum. Two that readers often miss: native USDC on Arc uses 18 decimals, not the 6 decimals used by USDC as an ERC-20 on many other chains, and wallets that cannot display a custom gas token may show balances as “ETH” even though the underlying token is USDC. Official docs also mention a mempool 20 gwei maxFeePerGas floor, and that some features (opt-in contract privacy; native wallet post-quantum signing) are on the roadmap rather than live. On-chain verification of a named post-quantum signature scheme is described as live on mainnet; native wallet signing is not. This page does not treat roadmap items as shipping features.

Gas token, fees and speed

Fees are denominated in USDC, officially described as making costs more predictable in dollar terms than a volatile gas coin. Official gas docs describe an EIP-1559-style market with EWMA smoothing. Official EVM-difference docs also state a 20 gwei floor on maxFeePerGas. This page does not quote a typical USD fee beyond the official “fees are in USDC” design; check a live fee estimate on the day you care about.

Official mainnet parameters include a block time of about 0.5 seconds and deterministic, sub-second finality, with official guidance that there is no need to wait for multiple block confirmations the way one might on a probabilistic chain. Official connecting docs list a public mainnet RPC at https://rpc.mainnet.arc.io.

Official explorer

Official connecting docs list explorer.arc.io as the mainnet explorer. You can look up a transaction, an address or a token without connecting a wallet. Bookmark official URLs from docs.arc.io. Do not trust an explorer or RPC from a DM or a look-alike domain, and never paste a seed phrase or private key into a website.

DEXs and memecoin launchpads

Official Arc documentation emphasises payments and stablecoin-native applications. It does not name a single official memecoin launchpad, and this page does not invent DEX names. A pool or a “stablecoin-native” label is not evidence that a token is safe or worth anything. Most new tokens fail. See spotting rugs.

Bridging basics

This is a description of official documentation, not an instruction to move funds. If you do not need an asset on Arc, you do not need to bridge.

Official docs describe moving USDC to Arc with Circle’s USDC Bridge / CCTP-based tools (including official “Bridge Kit” documentation). Each route has its own trust assumptions, fees and delays. This page does not tell you to buy USDC, to open a Circle account, or to use any particular on-ramp, and it does not publish contract addresses.

If you ever use a bridge, start from official Arc docs, confirm chain ID 5042, remember that native USDC decimals on Arc differ from USDC on many other chains, double-check the domain, and treat unsolicited bridge links as phishing. A wrong-network or wrong-decimals transfer can permanently lose funds or show a confusing balance.

How to evaluate a token on Arc

This is a reading list, not a trading method and not a reason to buy anything. Coverage on a newer chain can be uneven, and 18-decimal native USDC can confuse tools written for 6-decimal USDC.

  • Read the contract, holders and transactions on explorer.arc.io.
  • Look at the pool and recent trades on a public screener such as DEX Screener, if the pair is listed there.
  • Inspect holder clusters with Bubblemaps where the chain is covered.
  • Use GoPlus and Token Sniffer only if they actually support Arc for that contract.
  • Read spotting rugs and crypto research tools.

None of those tools can make a token safe.

Risks

  • Permissioned validators. Official docs describe a permissioned validator set. That is a different trust model from an open validator set.
  • USDC decimals and wallet display. Official docs warn that native USDC is 18 decimals, and that some wallets may show the gas token as “ETH.” Mis-reading a balance or a transfer amount can lose funds.
  • Roadmap is not mainnet. Official privacy and some post-quantum wallet features are described as planned, not as current guarantees.
  • New tokens are usually worthless.
  • Phishing. Prefer docs.arc.io and explorer.arc.io, not a chat link.

Nothing on this page is financial advice, a recommendation to hold USDC on Arc, or a suggestion to launch or trade a token.
